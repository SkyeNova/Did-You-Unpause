# Contributing

Did You Unpause? is a companion mod I built for myself and a small group of friends who use
[Flashback](https://github.com/Moulberry/Flashback) together. It's not a general-purpose project
with a roadmap, it exists to solve one specific annoyance we kept running into.

A few things worth knowing before you open an issue or a PR:

- I'll keep maintaining it as long as people are using it, but updates will be infrequent and
  driven by whatever's actually bothering us at the time, not a release schedule.
- I probably won't review or merge pull requests promptly, if at all. That's not a reflection on
  the contribution, I just don't want to promise a review process I won't keep up with.
- Bug reports and ideas are welcome as issues, but there's no guarantee of a fix or a timeline.
- If you want different behavior badly enough, forking is genuinely the best option, the mod is
  small and Apache-2.0 licensed specifically so that's easy to do.

If none of that puts you off and you still want to contribute: keep changes small and focused,
match the existing code style, and explain the "why" in your PR description. Thanks for
understanding the scope here.
